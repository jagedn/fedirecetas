# Fedirecetas

un simple bash para seleccionar una receta de un csv de forma aleatoria y publicar un toot con la lista de la compra (pedazo chorrada de repo, ya lo sé)

## Instrucciones

clonate el repo

crea un api token en tu cuenta del fediverso

ejecuta en una shell

`INSTANCE=https://social.jagedn.dev AUTH_TOKEN=xxxxxxxx ./publish.sh`

## Cron

puedes añadirlo a un cron del sistema y asi tener todos los dias una propuesta re receta
